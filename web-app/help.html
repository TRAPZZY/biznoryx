Can I upload different types of business data?

Yes. Different business datasets should use separate named data series.

For example, use one series for Monthly Sales and another for Transaction History. This lets BIZNORYX preserve each dataset's structure and historical comparisons independently.

Why was my upload rejected?

A file can be rejected when its structure does not match the selected data series or required validation rules.

  1. Review the validation message.
  2. Confirm the correct data series was selected.
  3. Confirm recurring files use a compatible column structure.
  4. Correct the file and upload it again.
What is the metric column?

The metric column is the numeric business value BIZNORYX uses to calculate performance for that dataset, such as revenue, amount or units.

When does data appear in Evidence Reports?

Data should enter evidence history only after the required processing and verification path succeeds. Rejected data should not be shown as verified evidence.

How do historical comparisons work?

BIZNORYX compares compatible confirmed periods from the same data series. Keeping recurring datasets in the correct series builds a consistent performance history.

What happens after I cancel my subscription?

Cancellation stops automatic renewal. When the subscription is Non-renewing, the current paid period remains available until it ends.

How do I resume subscription renewal?

Open Billing and select Resume renewal.

BIZNORYX securely asks Paystack to enable the existing subscription again. You do not need to create a second subscription while the existing paid period is still active.

Why is a payment missing from Billing History?

Billing History contains confirmed provider payments. A new payment can take a short time to appear while provider verification and webhook processing complete.

I cannot sign in. What should I check?
  1. Confirm the email address.
  2. Complete email verification if requested.
  3. Use password reset if necessary.
  4. If the problem continues, contact live support through 3CX.
Why am I seeing the wrong workspace?

Use the organization selector in the sidebar. Uploads, reports, billing and activity are scoped to the currently selected organization.

A page is not loading correctly.
  1. Retry the request once.
  2. Hard-refresh the browser.
  3. Confirm the correct workspace is selected.
  4. If the problem remains, contact live support.
